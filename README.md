# SOLO Skill 提分官

> SOLO挑战赛获奖用户诚意贡献，参赛发帖前先跑一遍，哪里扣分、怎么提分，一次说清。

## 这是什么

SOLO技能创作赛参赛者的提分伙伴。按官方4维度（实用性/创新性/完成度/体验感）评审你的Skill，找出扣分点，给出三档提分路线，帮你从"能跑"升级到"能获奖"。

## 核心能力

- **评审诊断** — 按官方4维度评分，每分有据
- **扣分证据** — 每个扣分点可追溯、可修复
- **三档提分** — 5分钟快修/30分钟提分/发布版增强
- **发布门控** — PASS/CONDITIONAL/FAIL，明确能不能发

## 快速开始

1. 将 `solo-skill-booster` 放入你的 `.trae/skills/` 目录
2. 在SOLO中说：`帮我评审一下这个Skill：/path/to/your-skill/`
3. 获得完整提分报告

## 三种评审模式

| 模式 | 触发词 | 输出 | 用时 |
|------|--------|------|------|
| 快速评审 | `快速评审` | 一屏总览+门控 | ~1分钟 |
| 完整评审 | `评审` / `帮我看看` | 完整6阶段报告 | ~3分钟 |
| 提分模式 | `提分` / `怎么提分` | 完整报告+详细提分路线 | ~5分钟 |

## 评分维度

| 维度 | 权重 | 核心问题 |
|------|------|----------|
| 实用性 | 30% | 解决真实痛点了吗？有用户画像吗？ |
| 创新性 | 25% | 和已有Skill有什么区别？ |
| 完成度 | 25% | 功能完整吗？有错误处理吗？ |
| 体验感 | 20% | 新手能上手吗？触发词清晰吗？ |

## 发布门控

| 等级 | 条件 | 建议 |
|------|------|------|
| PASS | 总分≥15，无P0 | 可以发布 |
| CONDITIONAL | 总分12-14，或有1个P0 | 修完P0再发 |
| FAIL | 总分<12，或P0≥2 | 大改后再评审 |

## 与同类工具的区别

| 维度 | 纯评审工具 | 本技能 |
|------|-----------|--------|
| 输出 | 告诉你哪里不行 | 告诉你哪里不行 + 怎么修 + 修完看什么 |
| 闭环 | 无 | 评审→提分→验证→再评审 |
| 参赛适配 | 无 | 对齐官方4维度，预估入围概率 |
| 提分路线 | 无 | 三档可执行方案 |
