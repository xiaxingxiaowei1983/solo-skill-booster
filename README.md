# SOLO Skill 提分官

> 对齐官方投稿关注点，新增"自进化力"评分；一份报告告诉你哪里扣分、怎么补分、能不能发布。

## 这是什么

SOLO技能创作赛参赛者的提分伙伴。对齐官方投稿关注点（实用性/创新性/完成度/易用体验），在此基础上新增第5维度——**自进化力**，帮你从"能跑"升级到"能获奖"。

不是裁判，只判对错。是教练，帮你变强。

## 核心能力

- **5维评分** — 5维×5分=25分制，每维都有提分空间
- **扣分证据化** — 每条证据9字段，可追溯、可修复
- **三档提分路线** — 5分钟快修/30分钟提分/发布版增强
- **安全扫描** — 检测硬编码密钥、注入风险、Agent卡死问题
- **自进化吸收** — 每次评审从被评Skill中吸收优点
- **发布门控** — PASS≥19/ CONDITIONAL 15-18/ FAIL<15

## 快速开始

1. 将本仓库放入你的 `.trae/skills/` 目录
2. 在SOLO中说：`用 solo-skill提分官 优化下我的 Skill`
3. 获得完整提分报告

## 三种评审模式

| 模式 | 触发词 | 输出 | 用时 |
|------|--------|------|------|
| quick | 快速自检 | 评分+门控+最快提分 | ~1分钟 |
| full | 完整评审（默认） | 完整报告（含安全扫描） | ~3分钟 |
| boost | 提分模式 | 评分+提分路线+验收标准 | ~5分钟 |

## 5维评分体系

| 维度 | 分值 | 说明 |
|------|------|------|
| 实用性 | 0-5 | 解决真实痛点了吗？有用户画像吗？ |
| 创新性 | 0-5 | 和已有Skill有什么区别？ |
| 完成度 | 0-5 | 功能完整吗？有错误处理吗？ |
| 易用/体验 | 0-5 | 新手能上手吗？触发词清晰吗？ |
| **自进化力** | 0-5 | Skill能从使用中变强吗？有复盘吸收吗？ |

**总分：25分**

## 发布门控

| 等级 | 条件 | 建议 |
|------|------|------|
| **PASS** | 总分≥19 + 无P0 + 安全通过 | 可以发布，冲击奖项 |
| **CONDITIONAL** | 总分15-18，或1个P0 | 修完P0再发 |
| **FAIL** | 总分<15，或P0≥2 | 大改后再评审 |

**安全红线**：硬编码敏感信息（API Key/密码/Token）= 直接FAIL
