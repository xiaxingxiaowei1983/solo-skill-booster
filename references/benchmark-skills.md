# 对比基准库 — SOLO Skill 提分官

> 预置 GitHub/SOLO 热门 Skill 的评分数据，用于对比分析

## 使用方式

在评审报告中引用对比基准时，从本文件中选取同类 Skill 作为参照。

### 1. planning-and-task-breakdown

| 属性 | 值 |
|------|-----|
| 来源 | GitHub: addyosmani/agent-skills |
| 作者 | Addy Osmani (Google Cloud AI Director) |
| Stars | 30k+ |
| 类型 | 方法论型 |
| 核心能力 | 将任务拆分为带验收标准和依赖顺序的小任务，反对"一口气写完" |

**评分**：

| 维度 | 得分 | 判断依据 |
|------|------|----------|
| 实用性 | 4/5 | 解决真实痛点（AI默认走最短路径），但场景集中在编码 |
| 创新性 | 3/5 | 任务拆解是常规方法，无突破性创新 |
| 完成度 | 4/5 | 核心功能完整，有 Red Flags 检查 |
| 体验感 | 4/5 | 有文档、触发词清晰、有样例 |
| 自进化力 | 3/5 | 有版本号，但无复盘吸收机制 |
| **总分** | **18/25** | B级 |

**亮点**：
- Rationalizations 反借口设计（提前列出AI会找的借口并反驳）
- Red Flags 红旗检查（看到信号就停手）
- 6阶段生命周期路由（DEFINE→PLAN→BUILD→VERIFY→REVIEW→SHIP）

- 被评Skill总分 18-20 → 对齐 planning-and-task-breakdown（B级基准）
