# 可视化报告样式指南

> Apple 风格设计规范，用于 SOLO Skill 提分官 HTML 可视化报告生成

## 设计原则

- **简洁克制**：不堆砌元素，每个组件有明确目的
- **信息密度适中**：双排卡片布局，每屏 2 个 Skill
- **视觉层次清晰**：标题 > 分数 > 徽章 > 描述 > 细节

## 排版规范

### 字体
- 主字体：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", "PingFang SC", sans-serif`
- 标题：700 weight，负字间距
- 正文：400 weight，自然行高 1.5

### 字号层级
| 元素 | 字号 | 字重 |
|------|------|------|
| 页面大标题 | 40px | 700 |
| 卡片标题 | 20px | 700 |
| 描述文字 | 13px | 400 |
| 徽章文字 | 10-11px | 600 |
| 扣分点/提分路线 | 12px | 400 |
| 迷你排行榜 | 10px | 400-700 |

### 间距
- 卡片内边距：18-22px
- 卡片间距：18px
- 组件间距：12-16px
- 元素间距：6-8px

## 布局规范

### 卡片结构
```
┌────────────────────────────────────────┬───────────────┐
│ 头部横排                                │ 右侧排名区     │
│ [排名框] 名称+描述+badges [评分圆圈]    │ #1 RANK       │
│                                         │ 17.5          │
├────────────────────────────────────────┤ S级           │
│ 左侧内容区                              │ 👍 87赞       │
│                                         │ PASS          │
│  雷达图（200×200）                      │ ─────────     │
│                                         │ 排行榜        │
│  四维度列表                             │ 1 K12... 17.5 │
│                                         │ ...           │
│  三大扣分点                             │ 9 图片... 10  │
│                                         │               │
│  提分路线                               │               │
└────────────────────────────────────────┴───────────────┘
```

### 双排网格
```css
display: grid;
grid-template-columns: repeat(2, 1fr);
gap: 18px;
```

### 响应式断点
- `max-width: 900px`：单排布局，右侧排名区隐藏

## 雷达图规范

### SVG 参数
- viewBox: `0 0 200 200`
- 中心点：`(100, 100)`
- 半径：75px
- 网格线：5 层同心圆
- 轴线：4 条（实用/创新/完成/体验）
- 数据区域填充：`rgba(0,113,227,0.08)`
- 数据区域描边：`#0071e3`，1.5px
- 数据点：3.5px 圆点
- 标签：11px，对应维度颜色

## 组件规范

### 迷你排行榜
- 宽度：150px
- 每项：排名(16px) + 名称(ellipsis) + 分数(彩色)
- 当前 Skill 高亮：背景 `#f5f5f7`，加粗
- Top3 排名加粗

### 签名区
- 图标：56×56px，圆角 14px，黑色渐变
- 名称：20px，700 weight
- 引言：15px，斜体
- 分隔线：40×3px，蓝绿渐变

## 使用方式

### 触发词
- `可视化报告` / `visual` / `生图`

### 输入
- Phase 7 生成的评审数据（JSON 格式）

### 输出
- 单个 `.html` 文件，可直接浏览器打开
- 包含：Hero + 卡片网格 + 关键发现 + 签名

### 数据格式
```json
{
  "skills": [
    {
      "name": "make-exam",
      "label": "K12考卷生成",
      "desc": "教师版/学生版双模板...",
      "likes": 87,
      "score": 17.5,
      "grade": "S",
      "gate": "PASS",
      "dims": {"实用性": 4, "创新性": 4, "完成度": 5, "体验感": 4},
      "deductions": [
        {"lv": "p2", "dim": "实用性", "text": "K12教师在SOLO中占比偏低（-1）"}
      ],
      "boosts": [
        ["5min", "差异化声明", "+1→18.5"]
      ]
    }
  ]
}
```
